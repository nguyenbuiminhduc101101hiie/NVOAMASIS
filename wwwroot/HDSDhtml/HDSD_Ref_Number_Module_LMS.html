Hướng Dẫn Sử Dụng - Quản Lý Ref Number trong LMS

1. Mục đích

Quản lý số Ref (Reference Number) theo từng tháng, giúp hệ thống tự động đánh số HBL/MBL khi tạo mới.

2. Truy cập chức năng

Menu: 1.7 Ref No trên thanh điều hướng bên trái.

3. Các trường dữ liệu

  • Month: Tháng cần quản lý số Ref
  • Year: Năm tương ứng
  • Ref Number: Số Ref cuối cùng đã sử dụng trong tháng/năm đó
  • Job Used / User ID Used Job: (Tuỳ chọn) thông tin tracking
  • HBL Used / User ID Used HBL: (Tuỳ chọn) thông tin tracking

4. Tác vụ chính

  • Insert: Thêm dòng mới cho tháng/năm chưa có
  • Edit: Chỉnh sửa số Ref
  • Reload: Làm mới dữ liệu

5. Ghi chú quan trọng

  • Hệ thống tự động tăng số Ref khi tạo mới HBL/MBL dựa theo dòng cấu hình tại đây.
  • Nếu không có dòng cho tháng/năm tương ứng, hệ thống sẽ không tạo số Ref.
